# 盲酌小程序重设计

四栏： 首页 / 酒局 / 酒识 / 我的。微信原生 tabBar，保留现有盲品流程。

- 首页：品酒打卡、最近酒卡、最近三条手记。
- 酒局：创建、输入房间码、现有酒局、演示揭晓。当前酒局仍是本地 Mock。
- 酒识：搜索及阅读四篇品鉴记录入门内容。
- 我的：本机手记、按实际成员记录计算的参与酒局数、再次制作酒卡。
- 打卡：填写名称、香型、闻香、入口、回味和备注，单独保存于 mz_tasting_journal_v1，不覆盖原有酒局数据。
- 酒卡：原生 Canvas 生成图片，预览、长按或保存相册后手动分享；不包含虚构二维码或已发布分享链接。

视觉：米纸 #f7f3eb、墨色 #28251f、朱红 #893e32；宋体字族、细分隔线与简洁文字导航。

字体使用 Songti SC / STSong / SimSun / Noto Serif CJK SC / serif 回退。未打包字体，不保证没有宋体的 Android 设备显示为宋体；如需全平台一致，需配置有授权且微信可访问的字体资源。

此次源码与本地数据检查不代表微信模拟器或真机验收。重点真机检查：四栏切换、键盘输入、Canvas 中文排版、相册授权和保存、宋体回退。

## 李白标志与酒识扩充

新增 assets/brand/libai.png：原创生成的抽象诗人举杯形象，朱红色、透明底。使用于首页、酒识、我的、Canvas 酒卡。为栅格素材，尚非矢量商标交付。
