# 小程序接口接入与发布前检查

更新日期：2026-11-10。当前接口说明以本文为准；早期 `welink-integration.md` 中的 JSESSIONID 登录方案保留作历史参考。下方真实接口记录来自 2026-11-06，本次登录持久化修复另列验收范围。

## 已完成的开发

- 登录：`POST /taste/userInfo/wxLogin` 接收 `code`、`avatarUrl`、`nickName`、`sex`，保存 `accessToken`、`openId` 和远端 `userId`。本机酒局使用的 `userId` 不被远端 ID 覆盖。
- 用户资料：`GET /taste/userInfo/{openid}/get` 读取服务端昵称、头像等资料；请求头自动带 `Authorization: Bearer <accessToken>`。
- 昵称：`POST /taste/userInfo/updateNick` 提交 `openid`、`nickname`，不再通过重复 `wxLogin` 更新昵称。
- 头像：`POST /taste/userInfo/uploadWxUrl` 使用 `wx.uploadFile`，文件字段为 `file`，表单携带 `openid`；支持 `http://tmp/`、`wxfile://` 等本机临时文件路径，兼容返回的 `file_url`。
- 酒款目录：`GET /taste/public/wineType` 用于酒款目录和酒款联想，保留最近成功缓存和内置目录降级。
- 酒文化：`POST /taste/public/knowledge`，JSON 参数 `{page,size}`，已接入“慢读文章”。支持实际 `records` 分页结构、正文 `paragraphs`、出处 `sources`、练习 `tip` 和更新日期；接口不可用时继续显示本地文章，不伪造在线内容。
- 成功码接受 `00000`；公开请求不携带身份凭证，公开接口失败不会清除登录态。本机微信身份与短期令牌分开保存；自然过期不退回游客，联网操作在发送前更新凭证，不重放已经发送的资料或品鉴写请求。

## 2026-11-10 登录持久化修复

- `isLoggedIn()` 读取本机已确认的身份，不因打开页面或令牌到期而清空头像、昵称和微信身份。主动退出、服务端拒绝当前有效凭证或更换后台仍会清理相应登录状态。
- 已登录用户下次联网操作前，若令牌已过期或重启后缺少凭证，使用 `wx.login` 换取新凭证；并发操作共用一次更新，不再次调用 `wx.getUserProfile`。首次登录和主动退出后的游客不会自动登录。
- 更新凭证必须匹配原 openid 和后台基地址；退出期间返回的旧登录响应会被丢弃，不能恢复已退出的账号。更新失败保留本机身份和资料，拦截待发送业务请求，后续操作可重试。
- 小程序环境不依赖 Node `Buffer` 或 `TextDecoder` 解析 JWT 过期时间；恢复的仅含 accessToken 的会话也会发送 Bearer 请求头。
- 开发者工具执行「重新打开此项目」后，「我的」仍显示原头像、昵称及「微信已登录」。没有修改用户资料或退出账号。
- 本轮 UI 复核发现旧在线接口返回 403 时不应清除已确认身份；现保留登录状态并显示功能访问失败，401 仍清理失效会话。
- 129 项 Node 回归测试通过，覆盖重启恢复、并发更新、断网恢复、退出竞态、账号/后台隔离、昵称同步、403 不误退出和写请求不重放；请求前换码在本轮 Network 中观察到 wxLogin 200，但后续旧在线列表仍 403，不能据此认定在线链路已通过，真机长时间使用尚未验收。

## 发布前需要处理的事项

1. **后端延长 accessToken 有效期或提供刷新机制。** 2026-11-06 实测 JWT 的 `exp - iat` 为 **8 秒**，本次未复测当前有效期。客户端已支持请求前换取新凭证；后端仍应避免过短有效期带来的频繁换码，以及请求途中到期的问题。客户端不会自动重放失败的写请求。
2. **微信公众平台上配置域名。** `request` 和 `uploadFile` 合法域名需包含 `https://applet.51welink.com`；头像等远程图片使用的 HTTPS 域名需按实际上传返回结果加入 `downloadFile` 合法域名。开发者工具关闭域名校验不能替代真机验证。
3. **隐私及权限配置。** 核对了头像选择、相册保存等说明；仍需在小程序后台确认实际使用的微信隐私接口已声明，并在真机检查授权弹窗。
4. **旧在线品鉴接口另行联调。** `/taste/applet/**` 不在本次提供的新接口清单中，相关本地功能保留。匿名 `GET /taste/applet/tastes` 当前返回 HTTP 403，未返回约定的业务 JSON，不能把在线创建、评分、结束和结果功能算作已验收。
