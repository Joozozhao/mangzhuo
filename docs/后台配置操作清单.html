必做 1配置服务器域名

路径：开发管理 → 开发设置 → 服务器域名 → 修改

  1. 点击「修改」，需管理员微信扫码确认身份
  2. 在 request 合法域名 中新增：
request 合法域名
https://applet.51welink.com
注意：必须是 https 且已备案域名；域名每月只能修改 5 次，务必一次填对。若后端还有 WebSocket，再在 socket 合法域名填 wss://applet.51welink.com（当前未见使用，可不填）。
配完后，开发者工具「详情 → 项目配置」里应能看到该域名；真机预览时在线品鉴才能正常请求。

必做 2用户隐私保护指引

路径：设置 → 服务内容声明 → 用户隐私保护指引 → 更新（或「去完善」）

后台会根据已提交代码自动列出涉及隐私的接口，每一项都要填用途，空着会导致线上接口被拦截。盲酌实际用到：

信息类型用途说明（直接复制填入）
相册（仅写入）权限用于将用户生成的品鉴酒卡图片保存到手机相册，便于分享与留存。
用户信息（微信昵称、头像）用户主动填写后，用于在酒卡与品鉴手记上展示昵称与头像。
如果后台还自动识别出「剪切板」等项，一律如实填写用途；不要勾选代码里根本没用的项，审核会核对调用。

页面继续往下的几项也必须填：

  • 你的权益：填客服邮箱或电话（必填）
  • 信息存储期限：勾选「实现处理目的所必要的最短时间」
  • 信息使用规则：填「弹窗提示」
  • 底部勾选「本小程序已对用户的信息处理进行了逐一说明」，点确定并提交
提交后需等审核通过（一般 1–2 个工作日）才会正式生效；生效前线上保存酒卡仍会报 privacy permission is not authorized。

必做 3确认服务类目

路径：设置 → 基本设置 → 服务类目

盲酌没有任何酒类销售行为（不含商城、不含支付下单），不要选「商家自营 - 酒」，该类目需《食品经营许可证》等资质，选了必被打回。

建议选择：

  • 工具 → 信息查询 或 工具 → 效率（品鉴记录、打分工具）
  • 如需体现内容属性，可加 教育 → 生活常识/知识科普（酒识页属知识内容）

必做 4提审前自查

路径：开发者工具 + 后台版本管理

  • 开发者工具「详情 → 基本信息」确认主包 < 2MB（当前约 472KB，盲品流程已在分包）
  • 工具顶部「代码质量分析」跑一遍，处理所有体验评分项
  • 真机预览四个 tab + 完整走一遍在线品鉴流程，确认域名白名单生效
  • 提交审核时填写测试账号（可填「无需登录，打开即用」，并附功能路径说明）
  • 备注中写明：本小程序不销售酒类，仅为品鉴记录与评分工具，已内置理性饮酒与未成年人禁饮提示
