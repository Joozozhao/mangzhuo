# 酒识知识库第一版

整理日期：2026-10-03。

## 已接入的内容

- 香型入门：12种常见香型，含学习介绍、对应标准编号、实施日期、核验状态、关联品牌和杯中练习。
- 盲品风味：24个编辑整理的感受记录词，分为闻香12个、入口6个、回味6个；不是某机构发布的官方风味轮。
- 名酒档案：13个品牌学习档案，覆盖12种香型，以实际产品和资料为线索；档案酒款不代表品牌所有系列。
- 慢读文章：保留原有11篇文章和出处。

香型采用学习目录，不表述为“十二大香型统一国标”。兼香入门引用的是浓酱兼香型标准；董香型 GB/T 10781.12-2026 的实施日期为2027-02-01，当前资料标记为即将实施。标准状态是资料核验时的快照，后续发版需重新查证，不通过本地时间自动宣称标准有效。

## 页面与业务衔接

1. 酒识主栏目展示香型、风味词与名酒档案，支持当前栏目搜索、详情阅读、关联阅读和复制资料来源链接。
2. 品酒打卡可按闻香、入口、回味选择实际感受到的词，保留自由填写。默认香型仍为“暂不判断”，从酒识进入不会预填理论风味。
3. 选词记录写入原有 `aroma / taste / finish` 字段，供原分享酒卡使用；另存 `flavorTagIds`，便于后续做个人风味统计。原打卡记录仍可读取。
4. 酒局揭晓页新增“揭晓之后，再认识这一杯”入口。品牌匹配使用已知名称与别名，并同时核对已揭晓的香型，不将“茅台镇”等产地字样当成品牌；未收录品牌可回退到香型介绍，未知香型不强行匹配。知识链接只在酒局状态为 `revealed` 时展示。
5. 数据随小程序本地打包，不请求知识服务器。当前功能不依赖新增 CloudBase 环境、数据库集合或付费接口。

## 数据结构

主要文件：

- `miniprogram/data/liquor-knowledge.js`：知识数据与来源注册表，以 CommonJS JavaScript 模块随小程序打包；微信运行时不能直接 `require` `.json` 文件，因此此处内容使用 JS 对象导出。
- `miniprogram/utils/liquorKnowledge.js`：搜索、统一详情、风味分组、揭晓酒样匹配。
- `miniprogram/utils/knowledgeNavigation.js`：跨 tab 的一次性详情定位；跳转失败清理待打开项。
- `miniprogram/utils/knowledge.js`：原有慢读文章。

JSON顶层包含 `schemaVersion`、`updated`、`editor`、`scope`、`sources`、`aromas`、`flavorGroups`、`brands`。

| 数据 | 关键字段 | 维护方式 |
|---|---|---|
| 来源 | id、title、url、kind、checkedAt | 每条来源记录核验日期；访问不稳定时记录 accessNote |
| 香型 | id、name、aliases、summary、paragraphs、standard、sourceIds、tip | 标准版本、状态和实施日期需一起维护 |
| 风味词 | id、label、desc、example | ID全库唯一；分组ID对应既有打卡字段 |
| 品牌 | id、name、aliases、aromaId、region、products、sourceIds | aromaId只描述本档案的学习酒款，不推定所有同品牌产品 |

以后迁移到用户自己的服务器，可以沿用此结构提供只读知识接口。第一版没有发布管理后台、自动抓取或线上增量更新。

## 资料来源与 GitHub 调研结论

标准元数据参考[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/std_list?p.p1=0&p.p2=%E9%A6%99%E5%9E%8B%E7%99%BD%E9%85%92&p.p90=circulation_date&p.p91=desc)，具体资料链接及核验日期均保存在JSON的 `sources` 中。

品牌事实以酒厂公开资料、文化机构资料为依据，正文为盲酌整理的简短介绍；风味词解释、例句和杯中练习为编辑内容。未导入外部图片、商标图或标准全文，不收录市场价格及保健功效宣传。

上一轮提及的 GitHub 线索重新核验后，未发现适合直接导入的完整白酒百科：

- [ymine的调酒演示页](https://github.com/HelloMInd-star/ymine/blob/main/labs/molecular-mixology.html)：包含白酒相关演示内容，不能直接视为可追溯的知识数据库，本版没有复制其代码或数据。
- [Code for SAKE](https://github.com/Code-for-SAKE)：日本酒开放数据项目，酒种不同，本版不导入。
- [Baijiu-ML-model](https://github.com/MOUTAI-Lee/Baijiu-ML-model)：酱香白酒感官质量预测研究代码，不是面向用户的百科数据，本版不导入。
- `WhiskyyDB/whisky-database`：本轮访问未成功，不能确认为可用资源，不采用。

后续新增条目先确认实际事实及来源，再编辑摘要并建立关联。对拟复用的外部代码、数据或图片，应逐项查看许可条件。
