2功能页面路径（提交时填「补充说明」或备注）

盲酌是一款白酒盲品品鉴工具，用于线下/线上品酒活动的记录、打分与结果揭晓，不涉及任何酒类销售、交易或支付。 【核心功能与路径】 1. 首页（pages/index/index）：开始盲品、查看今日推荐、品鉴手记入口 2. 酒局 tab（pages/gather/gather）：本地酒局列表 + 在线品鉴列表（按编号进入） 3. 盲品流程（分包 packages/blind）：创建酒局 → 设置酒样 → 邀请加入 → 盲品打分 → 提交 → 揭晓 → 对比 → 排行 → 生成报告 4. 在线品鉴（分包 packages/online）：发起在线品鉴（主持人口令）→ 进入场次竞猜与打分 → 结束并揭晓 5. 酒识（pages/knowledge/knowledge）：白酒香型、工艺等知识科普 6. 我的（pages/mine/mine）：我的手记、打卡、关于与隐私协议 7. 关于/隐私（pages/about/about）：隐私政策摘要、用户协议、免责声明、理性饮酒提示 【合规说明】 - 本小程序不销售酒类商品，无商城、无购物车、无支付下单功能，不属于电商经营行为； - 首屏与酒识页常驻「理性饮酒 · 未成年人请勿饮酒」提示，首次启动弹出确认； - 仅采集用户主动填写的昵称头像（用于酒卡署名）与相册写入权限（用于保存酒卡图片），数据本地存储，无第三方 SDK。

4常见驳回点与应对

驳回理由应对
涉及酒类销售需资质备注中强调「无销售/无支付」，类目选工具类；若仍被拒，补充《不涉及经营说明》截图

隐私指引未配置确认后台「用户隐私保护指引」已审核通过并生效（不是仅保存草稿）
功能无法体验/白屏真机预览确认在线品鉴域名已加入白名单；离线功能不依赖网络
诱导分享现有分享仅为结果卡片与活动邀请，无「分享得奖励」文案，保持现状
