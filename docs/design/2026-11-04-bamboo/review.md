# 竹影手札实施与公开酒款目录

用户已选择方案一。四个主页面、品牌栏与底部导航已迁移到微信原生小程序；打卡、酒卡、资料与在线品鉴通用控件衔接竹绿纸白配色。用户资料、手记、房间、身份校验和评分继续使用原有服务，没有迁移 HTML 原型的演示数据。

## 酒款接口

使用用户指定的 `GET https://applet.51welink.com/taste/public/wineType`。实际响应 `code` 为字符串 `00000`，`data` 包含 44 条，`count` 为 0，因此以 `data` 数组为准。参考价从字符串规范为数值；未知价格不补造。

- 公开目录请求独立于登录接口，不携带本项目维护的 Cookie 或 Authorization，不改动受保护 `/taste/applet/` 请求的校验与会话处理。
- 并发请求合并，成功目录在内存保留 10 分钟并缓存到本机。失败时使用最近成功目录，没有缓存才使用内置离线目录，界面明确提示并可重试。
- 「酒识 → 名酒档案」新增目录搜索、酒款详情与目录参考价；原品牌知识文章保留。
- 打卡、桌上盲品录入/猜酒、在线发起页共用目录选填。参考价不代表实时售价，允许修改。
- 缓存按基地址隔离，拒绝基地址变更后的过期响应；公开目录失败不清理登录会话。
