当前 Welink 后台接入说明与验收边界见 [docs/welink-integration.md](docs/welink-integration.md)。「酒局」提供本机桌上品鉴和在线品鉴；在线接口已在本地补齐，仍需后端部署与真实微信联调。下文保留早期 MVP 说明，原盲品页面现位于 `miniprogram/packages/blind/`。

## 一、项目架构与技术栈

- **前端技术栈**：微信原生小程序 + JavaScript (ES6+) + WXML + WXSS
- **设计规范**：东方雅致「米白 + 墨黑 + 金色」高级极简视觉体系，拒绝传统大红大金俗气风格。
- **数据与逻辑层**：
  - **当前状态**：内置本地存储与 Mock 数据闭环（`services/storage.js`），无需后端即可探索本地演示流程；真机与多设备联机能力需另行验证。
  - **云开发预留**：数据结构已严格按照微信云开发（CloudBase）集合设计，云端模型文档参见 `cloudfunctions/DATABASE_SCHEMA.md`。
- **打分引擎**：内置专业白酒盲品加权评分与对比分析器（`utils/scoring.js`），包括品牌（25分）、产品（25分）、香型（10分）、度数（10分）、年份（15分）、估价区间（15分）。

## 二、页面路径与功能清单

| 页面名称 | 路径 | 核心业务与交互功能 |
|---|---|---|
| **首页** | `/pages/index/index` | 品牌 Hero 展区、发起盲测、加入盲品、一键体验示例局、历史酒局记录 |
| **创建酒局** | `/pages/create/create` | 设置盲品局名称、寄语、盲品酒款数量 (2~8款)、人数上限 (4~12人)、评分规则一览 |
| **录入真实答案** | `/pages/setup/setup` | 房主专属密录各编号酒款信息（品牌、产品名、香型、度数、年份、真实价格、风味备忘），支持一键填充经典对比组 |
| **加入酒局** | `/pages/join/join` | 4位数字房间号快速入局、可进入酒局快捷选择 |
| **酒局大厅** | `/pages/room/room` | 房间码展区、全员盲品交卷进度、酒样盲品入口卡片、入局品鉴官列表、房主开奖触发器 |
| **盲猜阶段** | `/pages/tasting/tasting` | **第一阶段：你觉得这是什么酒？** 盲猜品牌、产品、香型、酒精度数、酿造年份、猜测售价 |
| **主观打分** | `/pages/scoring/scoring` | **第二阶段：抛开品牌，你真正喜欢它吗？** 5大感官维度（香气、入口、醇厚、协调、回味）动态滑块打分与短评 |
| **提交完成** | `/pages/submitted/submitted` | 盲品交卷封存确认、醒酒等待指引 |
| **开奖揭秘** | `/pages/reveal/reveal` | 房主揭晓真实酒款、大众综合均分、盲测估价 vs 真实售价、品牌猜中率与价格偏差对比 |
| **答案对比** | `/pages/compare/compare` | 深入单款酒查看全员猜测明细、各项得分拆解（命中/未命中标签）与口感短评 |
| **排行榜** | `/pages/ranking/ranking` | **双榜并立**：① 猜酒高手榜（谁最懂酒）+ ② 大众口味榜（脱去品牌与价格光环后哪款盲饮评分最高） |
| **酒局报告** | `/pages/report/report` | **核心爆款分享页**：全场最受欢迎酒款、最大性价比黑马、最难猜酒款、本场猜酒王 |
| **我的战绩** | `/pages/mine/mine` | 个人历史盲测统计、品牌命中率、盲品口味雷达画像 |

## 三、如何导入并在微信开发者工具中运行

1. 打开 **微信开发者工具** (WeChat DevTools)；
2. 点击 **「导入项目」** (Import Project)；
3. 选择目录：
   ```text
   /Users/joozo/Documents/Codex/2026-09-08/referenced-chatgpt-conversation-this-is-an/work/mangzhuo
   ```
4. AppID 可以选择 **「测试号」** (或使用个人注册的小程序 AppID)；
5. 开发模式选择 **「小程序」**，语言选择 **「JavaScript」**；
6. 点击打开，项目将立即在模拟器中启动！
7. **体验建议**：
   - 首页点击顶部 **「一键体验：周五酱浓盲品争霸赛」** 即可直接体验开奖揭秘、对比明细、双排行榜与酒局深度报告；
   - 点击 **「创建新酒局」** 体验自建房间、密填标准答案、邀请入局、逐款盲品与实时评分交卷。

## 四、下一步演进建议

1. **接入微信真实登录与授权**：在 `app.js` 与 `pages/join` 中调用 `wx.getUserProfile` 或新版头像昵称填写能力；
2. **迁移云开发**：将 `services/storage.js` 中的存储方法替换为 `wx.cloud.database()` API；
3. **海报分享生成**：在 `report/report` 页面引入 Canvas 绘制长图，便于玩家一键生成带名酒标签和盲品黑马金句的朋友圈海报；
4. **酒款知识库快选**：在 `setup` 与 `tasting` 页面中补充主流白酒（茅台、五粮液、剑南春、泸州老窖、郎酒、汾酒、西凤等）品牌与产品的输入联想与自动补齐。
